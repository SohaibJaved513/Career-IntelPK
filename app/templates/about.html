Project Case Study

How CareerIntelPK was built

A simple student portfolio project using Python, Flask, EDA, preprocessing, and CV skill-gap analysis.

Problem

Students apply blindly

Many students do not know which skills are repeatedly demanded in job listings.

Dataset

Pakistan job market CSV

The uploaded Kaggle CSV was cleaned, analyzed, and converted into dashboard-ready files.

Solution

Market + CV matching

The app compares CV skills with top market skills and recommends a learning roadmap.

Pipeline

Raw CSV → Data cleaning → Salary parsing → Skill splitting → Role classification → EDA files → Flask dashboard → CV Analyzer.
